# Vortex install 0.43.0.19

0.43.0.7 stays in Vortex until you install this 0.43.0.19 build over it.

1. Back up `HorizonUI.user.ini`, presets, and Message Log files first (copy or move; do not delete).
2. Build or take the 0.43.0.19 FOMOD from `%USERPROFILE%\build\HorizonUI-0.43.0.19-FOMOD.zip` (local Cursor agent steps in CHECKS_0.43.0.8.md).
3. In Vortex, install/replace the Horizon UI mod with the new FOMOD. Keep Core. Re-enable Comms, Scanner, and Scope if you use them.
4. Confirm `HorizonUI.log` says `HorizonUI 0.43.0.19 loaded`.
5. Leave 0.43.0.7 deployed until that install is done.
